About CYBERCRAFT

🔧 What is CYBERCRAFT?

CYBERCRAFT is a 100% static web-based encoding and decoding toolkit. All operations run entirely in your browser using JavaScript — no data is ever sent to any server.

✨ Features

  • ✅ Base64 — Encode & decode Base64 strings
  • ✅ ROT13 — Classic Caesar cipher with shift 13
  • ✅ URL Encoding — Encode/decode URL parameters
  • ✅ Hex & Binary — Convert between text, hex & binary
  • ✅ Caesar Cipher — Shift text by any number (1-25)
  • ✅ 100% Static — No backend, no tracking, no data collection
